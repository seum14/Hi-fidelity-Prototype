# Modern Sketching Tools | Website Prototype

A high-fidelity website prototype for a physical art-supplies retailer, designed to help visitors explore products, locate shop sections and find opening hours and contact information.

**Author:** [Khalid Hasan Seum](https://github.com/seum14) · **Focus:** Responsive design, interactive prototyping and usability evaluation

## The design brief

Modern Sketching Tools needed an informational website for its physical shop. The prototype refines an earlier low-fidelity design using user feedback and supports product discovery rather than online checkout.

## Main experiences

- **Home:** Product highlights, new arrivals, shop information and navigation.
- **Product discovery:** Category and product pages with descriptions, availability and prices.
- **Shop exploration:** An interactive floor plan linking visitors to product sections.
- **Practical information:** Opening hours, location and contact details.
- **Responsive interaction:** Mobile navigation, hover states and a dark-mode toggle.

## Usability evaluation

Five participants completed navigation tasks across the home, category and product pages. The evaluation recorded clicks, task completion time and error-correction time.

The documented recommendations focus on text readability, colour contrast, spacing and clearer navigation. Detailed observations and screenshots are included in the project document.
